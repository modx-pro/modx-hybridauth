# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.2.0-pl] - 2026-07-25

### Security
- Updated HybridAuth core to 3.13.0 (CVE-2026-4587).
- [#25] Reject off-site `redirectUri`; refuse rebinding an OAuth identity to another logged-in user.
- [#38] Facebook HTTPS: callback uses `hauth_done`; upgrade `http` `site_url` to `https` when the request is TLS.

### Added
- [#56] VkId provider (VK ID OAuth 2.1 + PKCE); legacy Vkontakte kept for old apps.
- Restored local providers removed upstream in 3.8.2: Vkontakte, Yandex, Odnoklassniki.
- [#32] `ha.keys.Yahoo` system setting and setup docs (Hybridauth `Provider\Yahoo`).
- `ha.keys.X` (OAuth 2); Twitter setting kept as legacy OAuth 1.0a.
- `ha.keys.Odnoklassniki` system setting.
- [#31] `&postHooks=` snippets; system events `OnHAUserCreate`, `OnHAUserLogin`, `OnHAUserBind`.
- [#54] Build runs `composer install` so transport packages include `vendor/autoload.php`; `composer.lock` committed for reproducible builds.
- Provider icons as inline SVG in chunks (`tpl.HybridAuth.provider*`): Simple Icons v16 (https://simpleicons.org, MIT); Yandex app icon from Yandex/Wikimedia; ModxPro logo from docs.modx.pro.
- LinkedIn/Yahoo: pinned last Simple Icons releases before brand removal.

### Fixed
- [#52] Odnoklassniki birthday parsing (`YYYY-MM-DD`); documented keys `id`/`key`/`secret`.
- [#47] Twitter OAuth1: keep/mirror `keys.key` (was dropped when normalizing to `id`).
- [#45] [#46] Guard `modUser` map composite on PHP 8+; safer `OnUserFormPrerender` / Profile access.
- [#36] Strip logout/auth query params on redirect and login link base URL.
- [#51] Remove unused FULLTEXT index on `ha_user_services.extended` (InnoDB error 1214).
- `ha_user_services.createdon` timestamp (was using month token instead of seconds).
- `getUrl()` respects HTTPS behind TLS proxy (same as OAuth callback).
- Unbind requires web session; guest gets `ha_err_not_logged_in`.

### Changed
- PHP 7.4–8.4 supported.
- Replaced legacy PNG icon sprites with official SVG brand icons (no custom drawing).
- Active/linked providers use CSS grayscale instead of a separate grayscale sprite.
- MailRu is not restored; use VK ID for Mail.ru accounts.
- Removed unused `$_SESSION['HA']['verified']` flag.
